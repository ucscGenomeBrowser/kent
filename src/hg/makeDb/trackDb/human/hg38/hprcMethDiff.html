Description

Part of the Imprinting track collection, this track shows the mean methylation difference between the maternal and the paternal haplotype at each CpG site, from 123 phased assemblies of the HPRC release 2 (50 female genomes for chromosome X). Positive values mean that the maternal copy is more methylated, negative values that the paternal copy is more methylated. The Kim DMRs track shows the regions where this difference is significant.

The authors calculated the values on the CHM13v2.0 reference. They were lifted to hg38 for this track, see Methods for details.

Display Conventions and Configuration

The track is a bar graph with one value per CpG site, about 26 million sites in total. Bars above the zero line (red) show higher methylation on the maternal haplotype and bars below it (blue) higher methylation on the paternal haplotype. When zoomed out, the maximum of all sites in a pixel is shown.

Methods

Oxford Nanopore reads with methylation tags from 123 HPRC release 2 samples were aligned to the personalized diploid assemblies with Winnowmap v2.03 (-x map-ont -I 8G --MD --cs -y -a -Y -L --eqx), keeping primary alignments, and methylation was called with modkit v0.4.1. Each diploid assembly was split by haplotype and chain files from haplotype to CHM13v2.0 were built with nf-LO and minimap2. Methylation calls were lifted to CHM13v2.0 with CrossMap v0.7.0, shifting negative-strand calls by 1 bp onto the C of the CpG. For each CpG and sample, the methylation fraction (methylated reads divided by all reads) was calculated for each haplotype, and the maternal minus paternal difference was averaged over all samples. CpG sites with missing values in more than 5% of samples were removed. For chromosome X, 50 female samples were used: the 25 with preferential inactivation of the maternal X and 25 randomly selected of the 34 with preferential inactivation of the paternal X, as determined from the methylation of the XIST promoter. See Lucas et al. for details on the HPRC data.

The data file all_chr.missingrate_5.createDiffDatasetFromMethylDataset.flipped.mean.grch38.bw was downloaded from the HPRC S3 bucket. The authors lifted it from CHM13v2.0 to hg38 with CrossMap and the chm13v2-grch38 chain file of the CHM13 project. We converted it to bedGraph and back to bigWig with our tools, which makes the file three times smaller without changing the values, see the makeDoc file.

Data Access

The data can be explored interactively in table format with the Table Browser or the Data Integrator and exported from there to spreadsheet or tab-sep tables. From scripts, the data can be accessed through our API, track=hprcMethDiff.

For automated download and analysis, the data is stored in a bigWig file that can be downloaded from our download server. The file for this track is called hprcMethDiff.bw. Individual regions or the whole genome can be obtained using our tool bigWigToBedGraph, which can be compiled from the source code or downloaded as a precompiled binary for your system. Instructions for downloading source code and binaries can be found here. The tool can also be used to obtain values within a given range, e.g. bigWigToBedGraph http://hgdownload.soe.ucsc.edu/gbdb/hg38/imprinting/hprcImprint/hprcMethDiff.bw -chrom=chr21 -start=0 -end=100000000 stdout

The original data files, in hg38 and CHM13v2.0 coordinates, can be downloaded from the HPRC S3 bucket.
