About Taxonium

Taxonium is a web application for exploring phylogenetic trees. Find out more at the Github repository (https://github.com/theosanderson/taxonium) or read the documentation (https://docs.taxonium.org).

About the tree

This tree was constructed by the Pathogen Genomics Group at the University of California Santa Cruz (UCSC) Genomics Institute. Our automated pipeline downloads Influenza A sequences from GenBank (i.e. the INSDC databases) and SRA assemblies from https://github.com/andersen-lab/avian-influenza/, identifies isolates that belong to the H5N1 clade 2.3.4.4b genotype D1.1 branches of per-segment trees, concatenates the segments of each isolate in largest to smallest order (PB2, PB1, PA, HA, NP, NA, MP, NS), aligns the concatenated sequences to a concatenated reference (PQ664446.1, PQ798039.1, PQ859340.1, PQ663857.1, PQ585621.1, PQ664459.1, PQ663860.1, PQ797957.1), using nextclade, and runs UShER to infer the tree structure and matOptimize to improve it under maximum parsimony.

About the metadata

In addition to metadata from GenBank and https://github.com/andersen-lab/avian-influenza (date, country, host, etc.), five HA phenotype scores were calculated from Deep Mutational Scanning (DMS) experiments performed by the Bloom lab at the Fred Hutchinson Cancer Center (https://dms-vep.org/Flu_H5_American-Wigeon_South-Carolina_2021-H5N1_DMS/):

  • Mouse sera escape relative to AmWigeon/SC/2021
  • Ferret sera escape relative to AmWigeon/SC/2021
  • Cell entry
  • Stability
  • Increase in a2,6 sialic acid usage
as well as one PB2 phenotype: Differential selection in human vs. avian cells. The scores displayed for each sequence were calculated by summing the per-mutation scores for all mutations found in that sequence.
