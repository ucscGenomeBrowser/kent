Description

This track is part of the Deleteriousness Predictions collection. The mitochondrial genome (chrM) encodes 13 proteins of the respiratory chain plus the 2 rRNAs and 22 tRNAs needed to translate them, and is present in hundreds to thousands of copies per cell, so a variant can affect all copies (homoplasmy) or only some (heteroplasmy). Most pathogenicity predictors are trained on nuclear genes, which is why the ACMG/AMP recommendations for mitochondrial variants name mtDNA-specific tools such as APOGEE and MitoTIP for computational evidence.

The MitImpact APOGEE 2 track shows data from MitImpact, a collection of pre-computed annotations for all three possible substitutions at every position of chrM, almost 50,000 variants. This track shows the gene and predicted effect of each variant and the score, class and probability of pathogenicity from APOGEE 2 (missense variants) or nAPOGEE (rRNA and tRNA variants). The scores are also shown as bars in the APOGEE2 / nAPOGEE track.

Display Conventions and Configuration

Each variant is a 1 bp feature labeled with its HGVS name on the rCRS (NC_012920.1), e.g. m.3243A>G. Positions where two genes overlap (MT-ATP8/MT-ATP6, MT-ND4L/MT-ND4) and a few tRNA boundaries carry each variant twice, once per gene, as the scores differ between the two genes. These variants are all drawn in magenta, whatever their class, to show how many there are. Hover over a variant to see the APOGEE prediction, click it for the annotations. The details page links to the variant's page on the MitImpact website. Variants can be searched by HGVS name or dbSNP rs ID in the position box.

Variants in overlapping genes are magenta. Other variants are colored by their APOGEE 2 class if they are missense variants and by their nAPOGEE class if they are in an rRNA or tRNA gene. Both models use the same seven classes; the thresholds are listed in the Methods section.

  VUS, variant of uncertain significance

  Variant in two overlapping genes, listed once per gene (colored like this whatever the class)
  Not scored by APOGEE 2 or nAPOGEE: synonymous, stop-gain, stop-loss and some start codon variants, control region (D-loop) and intergenic variants

The track configuration page has filters for the APOGEE class, the model (APOGEE 2 or nAPOGEE), the probability of pathogenicity, the region type (protein-coding, rRNA, tRNA, control region, intergenic), the predicted effect and the gene.

Methods

MitImpact (Castellana et al. 2015, 2021) annotates every possible single-nucleotide substitution of the rCRS with SnpEff and gene and protein identifiers, and with the scores of many predictors. APOGEE 2 (Bianco et al. 2023) is the mtDNA-specific meta-predictor recommended for missense variants. It is a bagging ensemble of k-nearest-neighbor classifiers with random undersampling and SMOTE oversampling, trained on 1,874 manually curated missense variants (140 pathogenic or likely pathogenic MITOMAP disease variants, 1,734 benign MITOMAP general variants) using 17 mitochondrion-specific evolutionary, structural and positional features and the outputs of other predictors. Its score is converted to a Bayesian probability of pathogenicity, which defines the classes: Benign < 0.062, Likely benign 0.062-0.265, VUS- 0.265-0.396, VUS 0.396-0.544, VUS+ 0.544-0.716, Likely pathogenic 0.716-0.907, Pathogenic ≥ 0.907 (probability thresholds). nAPOGEE, introduced with MitImpact 4, applies the same seven classes to rRNA and tRNA variants, with separate thresholds for tRNAs and rRNAs. nAPOGEE has not been published yet.

The file MitImpact4_V059.zip (MitImpact 4, release V059, built 2026-10-17) was downloaded from the MitImpact download page. A Python script converted each of its 49,882 rows to one bigBed feature, keeping the columns about the variant, the gene and the effect, the dbSNP identifier and the APOGEE 2 and nAPOGEE columns. The reference allele of every row was checked against chrM of hg38, which is the rCRS; all matched, including the four variants at position 3107, where the rCRS has an N. The APOGEE 2 and nAPOGEE classes were merged into one field with one spelling to color the features. 174 variants (at 58 positions) have two rows, one for each of two overlapping genes, which are colored magenta. The commands are in the makeDoc file, the scripts in our source repository.

Data Access

The data can be explored interactively in table format with the Table Browser or the Data Integrator and exported from there to spreadsheet or tab-sep tables. From scripts, the data can be accessed through our API, track=mitImpact.

For automated download and analysis, the annotation is stored in a bigBed file that can be downloaded from our download server. The file for this track is called mitImpact.bb. Individual regions or the whole annotation can be obtained using our tool bigBedToBed, which can be compiled from the source code or downloaded as a precompiled binary for your system. Instructions for downloading source code and binaries can be found here. The tool can also be used to obtain features within a given range, e.g. bigBedToBed http://hgdownload.soe.ucsc.edu/gbdb/hg38/mitImpact/mitImpact.bb -chrom=chrM -start=3200 -end=3300 stdout

The original data can be downloaded from the MitImpact download page. APOGEE 2 and nAPOGEE are licensed for non-commercial use only (CC BY-NC 4.0). Please cite MitImpact and the APOGEE 2 publication.
