Description

Beyond the base sequence, a chromosome carries chemical marks and a folded three-dimensional shape, both of which relate to whether the DNA underneath is being transcribed. These tracks show the fraction of DNA molecules carrying a methyl group on each CpG, and the split of the genome into the two large compartments seen in Hi-C data: an open, gene rich A compartment and a closed, heterochromatic B compartment.

This collection holds the 5mC Methylation, Compartment E1 and A/B Compartments tracks. Each has its own description page with the details of how it was made, reachable from the track name in the browser or from the list below the configuration controls on this page.

Data Access

The individual track description pages carry the download and intersection instructions for each annotation. The original files are on GenomeArk, in the bTaeGut7 annotations directory.
