# The DMC bigWig is used unchanged (chromosome names are already UCSC style and
# match hg38 chrom.sizes).
#
# The DMR bed has the signed maternal minus paternal methylation difference in the score
# column, which a bed9 score cannot hold. The script moves it to a float field
# (methDiff), adds the haplotype as a string field (parent), sets the score to 0 and
# leaves the name empty (tab-separated, bedToBigBed -tab, so an empty field is fine).
# Colors are a strong pink (230,40,140, maternal) and a strong blue (0,60,200,
# paternal) instead of the pale colors of the authors.
