Description

This track collection shows TAD domains called by the ENCODE uniform Hi-C pipeline with the Arrowhead algorithm (Juicer) across 16 mouse biosamples (ENCODE calls them "contact domains"). Each subtrack is one biosample.

The domains were called on mm10. On mm39, they are lifted from mm10, which is noted in each track's long label.

Display Conventions and Configuration

Subtracks are colored by organ. Mousing over a domain shows the biosample and the Arrowhead corner score. A higher corner score means the spot is more likely to be a domain corner. The details page also reports Arrowhead's upper/lower variance and sign scores, rounded to three decimal places. These calls use a different algorithm and finer resolution (5 kb) than the Dixon domains, produce smaller domains, and are not directly comparable to them.

Subtracks can be filtered on the track configuration page by:

  • Organ
  • Biosample type (cell line, primary cell, tissue)
  • Assay (intact or in situ Hi-C)
  • Life stage

Methods

Contact domains were produced by the ENCODE uniform Hi-C processing pipeline (Aiden lab, built on Juicer), which calls domains with Arrowhead. For each biosample, one representative experiment was selected, preferring an untreated baseline over a perturbed experiment where both were available. Its contact-domain files were then combined:

  • Each Juicer/Arrowhead record, which lists the same domain as a pair of anchors, was reduced to a single domain interval.
  • The five Arrowhead scores were kept.
  • Replicate calls whose endpoints fell within one 5 kb bin were merged, keeping the call with the higher corner score.

For mm39, the mm10 domains were lifted with liftOver, and lifted domains that came out more than twice their mm10 size were removed. The chosen ENCODE experiment accession is given in each subtrack's long label and links to the ENCODE portal.

Data Access

The raw data can be explored interactively with the Table Browser or the Data Integrator. For programmatic access, the track can be accessed using the Genome Browser's REST API. The underlying bigBed files can be downloaded from our download server. The original data files are also available from the ENCODE portal.
