Description

The My Annotations track lets you create, edit, and share your own set of annotations directly in the Genome Browser. You need to be signed in to your Genome Browser account to use it.

Important: This feature is intended for exploratory, educational, and demonstration use only. It must not be used to enter, store, or share private patient data, identifiable clinical records, or any other protected health information. Items written to a My Annotations track are stored on shared UCSC infrastructure and may be visible to other people when shared.

Display Conventions and Configuration

Each annotation is drawn as a box covering its position, in the color you picked. A transcript annotation is drawn with its exons and introns. A short mouseover label and a longer free-text description may be attached to each one.

Adding and Editing Annotations

Press Add Annotation above the browser image to open the entry form. You can look up a position by HGVS term, by coordinates, or by gene symbol, and the form fills in from what it finds. You can also type the fields in by hand, and add custom fields of your own. An annotation can also be created by drag-selecting a region on the browser image and choosing Add Annotation from the popup menu. Existing annotations can be edited or deleted at any time from their details page.

Sharing

Each My Annotations track has one share link. Anyone holding that link can see the track; if you created the link with edit access, they can change it too. You can switch the link between view and edit later, which changes what everyone already holding it can do, and you can revoke it at any time.

A shared track is loaded automatically the next time the recipient opens the Genome Browser, similar to a shared online document. The most recent write wins; there is no per-annotation revision history at this time.

Data Access

Each of your annotation tracks is stored as its own custom track. The download links, in tab-separated and Excel-ready comma-separated form, are on the track settings page, along with the sharing controls. A track's page offers that track's annotations, and also a single file with all of your tracks, which names each annotation's track in the first column.

To choose a region, a subset of fields, or another output format instead, open the Table Browser, which works on the assembly you are currently browsing. The data are not part of the public UCSC database and are not available through the public REST API or the bulk download server.
