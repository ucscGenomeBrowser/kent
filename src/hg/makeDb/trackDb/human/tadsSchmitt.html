Description

This track collection shows TAD boundaries across 21 human samples (7 cell lines and 14 primary tissues) from Schmitt et al., 2016. These are boundaries, not domains. For TAD domains, see the Dixon 2012 TADs track.

Display Conventions and Configuration

Each boundary is a 40 kb region, the bin size used in the Hi-C analysis. Subtracks are grouped by sample type (cell line or primary tissue) and organ system, and colored by organ system. Turning on several subtracks shows which boundaries are shared across samples. By default, 5 samples are shown: GM12878, H1-hESC, IMR90, dorsolateral prefrontal cortex, and liver.

Methods

Boundaries were called by Schmitt et al., 2016 with the insulation score method at 40 kb resolution. On hg19, they are shown at the positions listed in Supplementary Table S3 of that paper. On hg38, they were lifted with the UCSC liftOver tool, and a small fraction of bins that could not be lifted were dropped. Lifted bins that came out more than twice their original size were also removed.

Data Access

The raw data can be explored interactively with the Table Browser or the Data Integrator. For programmatic access, the track can be accessed using the Genome Browser's REST API. The underlying bigBed files can be downloaded from our download server.
