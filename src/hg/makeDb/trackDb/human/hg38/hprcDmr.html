Description

Part of the Imprinting track collection, this track shows differentially methylated regions (DMRs) between the maternal and the paternal haplotype. They were identified from 123 phased assemblies of the HPRC release 2 (50 female genomes for chromosome X). The track has 870 regions. A region where the maternal copy is more methylated than the paternal copy is a candidate for a locus that is imprinted by methylation of the maternal allele, and the reverse holds for the paternal copy.

The authors calculated the regions on the CHM13v2.0 reference. They were lifted to hg38 for this track, see Methods for details.

Display Conventions and Configuration

Each region is colored by the parent whose haplotype has the higher methylation level, and by the size of the difference, as classified by the authors:

  Red: higher methylation on the maternal haplotype, difference 0.15 or more
  Light red: higher methylation on the maternal haplotype, difference below 0.15
  Blue: higher methylation on the paternal haplotype, difference 0.15 or more
  Light blue: higher methylation on the paternal haplotype, difference below 0.15

The methylation difference, maternal minus paternal, is shown on the details page and when the mouse is moved over a region. It is positive for red and negative for blue regions. The track can be filtered by haplotype, by strong or moderate difference and by the methylation difference itself.

Methods

Oxford Nanopore reads with methylation tags from 123 HPRC release 2 samples were aligned to the personalized diploid assemblies with Winnowmap v2.03 (-x map-ont -I 8G --MD --cs -y -a -Y -L --eqx), keeping primary alignments, and methylated and total read counts per CpG were obtained with modkit v0.4.1. Each diploid assembly was split by haplotype and chain files from haplotype to CHM13v2.0 were built with nf-LO and minimap2. Methylation calls were lifted to CHM13v2.0 with CrossMap v0.7.0, shifting negative-strand calls by 1 bp onto the C of the CpG. For chromosome X, the samples were classified by the methylation of the XIST promoter on each haplotype, which shows which parental X is preferentially inactivated. Of 59 female samples, 25 had preferential maternal and 34 preferential paternal X inactivation; all 25 of the first group and 25 randomly selected samples of the second were used. Differential methylation was tested per chromosome with DSS v2.58.0 in R v4.5.3. CpG sites with missing data in more than 5% of samples were removed. A paired design was used, with the model ~ haplotype + sample fitted with DMLfit.multiFactor and a Wald test of the haplotype term with DMLtest.multiFactor. DMRs were called with callDMR (p-value below 0.001, otherwise default parameters). Neighboring DMRs within 1,000 bp with the same direction were merged, which reduced 1,509 regions to 880. Regions with an absolute difference of at least 0.15 were classified as strong, the others as moderate. See Lucas et al. for details on the HPRC data.

The data files were downloaded from the HPRC S3 bucket, file dmrs.N05_filt.all_chr.1e3.mrg.forPlotting.grch38.mrg.coordinate_fix.bed.gz. The authors lifted the 880 regions from CHM13v2.0 to hg38 with CrossMap and the chm13v2-grch38 chain file of the CHM13 project. 10 regions could not be lifted. Fragments of the same region that were on the same chromosome and at most 10,000 bp apart were merged again, which gave 870 regions. We converted the file to a bigBed file and added the haplotype, the strong/moderate class and the signed methylation difference as separate fields (the source file has the absolute difference and the direction in a separate column), see the makeDoc file and the scripts. No region was dropped.

Data Access

The data can be explored interactively in table format with the Table Browser or the Data Integrator and exported from there to spreadsheet or tab-sep tables. From scripts, the data can be accessed through our API, track=hprcDmr.

For automated download and analysis, the genome annotation is stored in a bigBed file that can be downloaded from our download server. The file for this track is called hprcDmr.bb. Individual regions or the whole genome annotation can be obtained using our tool bigBedToBed, which can be compiled from the source code or downloaded as a precompiled binary for your system. Instructions for downloading source code and binaries can be found here. The tool can also be used to obtain features within a given range, e.g. bigBedToBed http://hgdownload.soe.ucsc.edu/gbdb/hg38/imprinting/hprcImprint/hprcDmr.bb -chrom=chr21 -start=0 -end=100000000 stdout

The original data files, in hg38 and CHM13v2.0 coordinates, can be downloaded from the HPRC S3 bucket.
