Description

This track is part of the SNV Frequencies collection. It shows coding variants from the IBDseq browser of the Inflammatory Bowel Disease (IBD) Sequencing Consortium. Its phase 1 dataset contains the exomes of almost 29,000 individuals with Crohn's disease, 18,000 with ulcerative colitis, 3,400 with inflammatory bowel disease of undetermined type, and more than 97,000 controls. The track contains 21 million variants, most of them rare.

For every variant, the track shows the allele counts and allele numbers in all IBD cases and in controls, so allele frequencies can be compared between the two. The cases are also split into Crohn's disease (CD) and ulcerative colitis (UC).

Display Conventions

Each variant is drawn as a VCF item. Clicking a variant shows its details page with the consequence on the canonical transcript, the HGVS notation, the CADD, REVEL, PolyPhen-2, SIFT and SpliceAI scores, the gnomAD v4.1 non-Finnish European allele frequency, and the case and control counts. Many variants outside the coding regions have no consequence annotation.

The original file lists the counts and association results per analysis group: IBD, all cases, CD and UC. The field groups lists the groups in which a variant was counted, and the fields ac_case, an_case, ac_ctrl, an_ctrl, the meta-analysis results P_meta, BETA_meta and HetP, and the results for each sequencing batch (P_Twist, BETA_Twist and so on) list one value per group, in the same order. To make this easier to read, we added these fields:

  • AC_CASE, AN_CASE, AF_CASE: allele count, allele number and frequency in all IBD cases (group IBD)
  • AC_CTRL, AN_CTRL, AF_CTRL: the same in controls
  • AC, AN, AF: cases and controls together
  • AC_CD, AF_CD, AC_UC, AF_UC (and the matching AN_ fields): counts and frequencies in Crohn's disease and ulcerative colitis cases, if the variant was counted in that group

The track can be filtered on all of these frequencies.

Methods

The IBD Sequencing Consortium, formed in 2014 and part of the International IBD Genetics Consortium, has sequenced more than 50,000 patients from 50 research cohorts worldwide together with the Broad Institute. Earlier analyses, such as Sazonovs et al. (2022), were mostly of European and Ashkenazi Jewish individuals; the current dataset adds individuals of African-American, Latin American and Asian ancestry. As the exomes were captured with several kits over ten years, the analysis was done per sequencing batch (Broad Twist, Broad Nextera, Sanger exomes, Sanger genomes, UK Biobank exomes and Regeneron exomes) and combined by meta-analysis. Details of the phase 1 dataset are not yet published; the IBDseq browser About page describes the project, and the 2022 paper below describes the methods of the earlier Crohn's disease analysis.

The variant results VCF file IBD_variant_results.vcf.bgz (release of October 19, 2026) was downloaded from the IBDseq downloads page. It is already on GRCh38 and needed no liftover. A script added descriptions to the INFO fields, which were empty in the original file, changed the per-group fields to a variable number of values, as the number of groups differs between variants, and added the summary fields described above. The source file has 30,882,403 records. 10,007,245 of them have an annotation but no analysis group and no counts at all; these were removed, which leaves 20,875,158 variants. For 164 of them, the counts are only given for ulcerative colitis, not for all IBD cases, so they have no AC_CASE, AC_CTRL or AF fields. The steps are documented in our makeDoc file, and the script erbToVcf.py is in the scripts directory.

Data Access

Since the data can be downloaded from the IBDseq website, and does not seem to be under a license, we assume that we are allowed to redistribute it in VCF format. The data can be explored interactively with the Table Browser or the Data Integrator and exported from there to spreadsheet or tab-sep tables. From scripts, the data can be accessed through our API, track=ibdseq.

For automated download and analysis, the VCF file ibdseq.vcf.gz and its tabix index can be downloaded from our download server. The original data, together with gene-level results, can be downloaded from the IBDseq downloads page.
