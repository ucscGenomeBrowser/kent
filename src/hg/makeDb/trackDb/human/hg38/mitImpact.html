Description

This track is part of the Deleteriousness Predictions collection. The mitochondrial genome (chrM) encodes 13 proteins of the respiratory chain plus the 2 rRNAs and 22 tRNAs needed to translate them, and is present in hundreds to thousands of copies per cell, so a variant can affect all copies (homoplasmy) or only some (heteroplasmy). Most pathogenicity predictors are trained on nuclear genes, which is why the ACMG/AMP recommendations for mitochondrial variants name mtDNA-specific tools such as APOGEE and MitoTIP for computational evidence.

The MitImpact APOGEE 2 track shows data from MitImpact, a collection of pre-computed annotations for all three possible substitutions at every position of chrM, almost 50,000 variants. For each variant it gives the gene and predicted effect, the class and probability of pathogenicity from APOGEE 2 (missense variants) or nAPOGEE (rRNA and tRNA variants), more than 30 other prediction scores, conservation, MitoTIP for tRNAs, ClinVar and MITOMAP disease annotations, and allele frequencies from gnomAD, HelixMTdb, ToMMo 61KJPN and GenBank.

Display Conventions and Configuration

Each variant is a 1 bp feature labeled with its HGVS name on the rCRS (NC_012920.1), e.g. m.3243A>G. Positions where two genes overlap (MT-ATP8/MT-ATP6, MT-ND4L/MT-ND4) and a few tRNA boundaries carry each variant twice, once per gene, as the scores differ between the two genes. Hover over a variant to see the main predictions, click it for all annotations, including a table of all other predictors and a table of allele frequencies. The details page links to the variant's page on the MitImpact website. Variants can be searched by HGVS name or dbSNP rs ID in the position box.

Variants are colored by their APOGEE 2 class if they are missense variants and by their nAPOGEE class if they are in an rRNA or tRNA gene. Both models use the same seven classes; the thresholds are listed in the Methods section.

The track configuration page has filters for the APOGEE class, the model (APOGEE 2 or nAPOGEE), the probability of pathogenicity, the region type (protein-coding, rRNA, tRNA, control region, intergenic), the predicted effect and the gene.

Methods

MitImpact (Castellana et al. 2015, 2021) annotates every possible single-nucleotide substitution of the rCRS with SnpEff, gene and protein identifiers, conservation scores (UCSC PhyloP and PhastCons, 100 vertebrates and 470 mammals) and the scores of many predictors, some run by the MitImpact authors (e.g. PolyPhen-2, SIFT, PROVEAN, the TransFIC transforms, COVEC WMV), others taken from their sources or from dbNSFP (e.g. MutationTaster, DEOGEN2). APOGEE 2 (Bianco et al. 2023) is the mtDNA-specific meta-predictor recommended for missense variants. It is a bagging ensemble of k-nearest-neighbor classifiers with random undersampling and SMOTE oversampling, trained on 1,874 manually curated missense variants (140 pathogenic or likely pathogenic MITOMAP disease variants, 1,734 benign MITOMAP general variants) using 17 mitochondrion-specific evolutionary, structural and positional features and the outputs of other predictors. Its score is converted to a Bayesian probability of pathogenicity, which defines the classes: Benign < 0.062, Likely benign 0.062-0.265, VUS- 0.265-0.396, VUS 0.396-0.544, VUS+ 0.544-0.716, Likely pathogenic 0.716-0.907, Pathogenic ≥ 0.907 (score thresholds). nAPOGEE, introduced with MitImpact 4, applies the same seven classes to rRNA and tRNA variants, with separate score thresholds for tRNAs (benign ≤ 0.0914, likely benign ≤ 0.4283, VUS- ≤ 0.5232, VUS ≤ 0.5988, VUS+ ≤ 0.6714, likely pathogenic ≤ 0.7607, pathogenic above) and rRNAs (benign ≤ 0.4304, likely benign ≤ 0.5769, VUS- ≤ 0.6324, VUS ≤ 0.6878, VUS+ ≤ 0.7546, likely pathogenic ≤ 0.8653, pathogenic above). nAPOGEE has not been published yet. MitoTIP scores for tRNA variants and the disease and GenBank frequency data come from MITOMAP, ClinVar fields from the ClinVar VCF, population frequencies from gnomAD v3.1, HelixMTdb (2020-03-27) and ToMMo 61KJPN. See the MitImpact output legend for the ranges and thresholds of all other predictors.

The file MitImpact4_V059.zip (MitImpact 4, release V059, built 2026-10-17) was downloaded from the MitImpact download page. A Python script converted each of its 49,882 rows to one bigBed feature, keeping all 144 columns. The reference allele of every row was checked against chrM of hg38, which is the rCRS; all matched, including the four variants at position 3107, where the rCRS has an N. The APOGEE 2 and nAPOGEE classes were merged into one field with one spelling to color the features, and the predictor and frequency columns were also packed into the two tables on the details page. The commands are in the makeDoc file, the scripts in our source repository.

Data Access

The data can be explored interactively in table format with the Table Browser or the Data Integrator and exported from there to spreadsheet or tab-sep tables. All 144 MitImpact columns are included. From scripts, the data can be accessed through our API, track=mitImpact.

For automated download and analysis, the annotation is stored in a bigBed file that can be downloaded from our download server. The file for this track is called mitImpact.bb. Individual regions or the whole annotation can be obtained using our tool bigBedToBed, which can be compiled from the source code or downloaded as a precompiled binary for your system. Instructions for downloading source code and binaries can be found here. The tool can also be used to obtain features within a given range, e.g. bigBedToBed http://hgdownload.soe.ucsc.edu/gbdb/hg38/mitImpact/mitImpact.bb -chrom=chrM -start=3200 -end=3300 stdout

The original data can be downloaded from the MitImpact download page. The columns keep the licenses of their sources, which are listed on the MitImpact license page. APOGEE 1, APOGEE 2 and nAPOGEE are licensed for non-commercial use only (CC BY-NC 4.0), and so are the ToMMo 61KJPN, CADD, PolyPhen-2, MutationTaster, DEOGEN2, VEST, CHASM and LIST-S2 columns. Please cite MitImpact and the sources of the columns you use.
