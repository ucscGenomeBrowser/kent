Description

Tumors acquire somatic mutations that are not present in the germline of the patient. Counting how often the same mutation is found in patients with a given cancer type helps to separate recurrent driver mutations from rare passenger mutations.

This collection contains tracks with somatic mutations found by sequencing tumor samples:

  • Cancer Mutation Atlas: 3.9 million somatic variants from 12 sequencing studies, with the number of patients carrying each variant and the number of patients tested, for more than 800 OncoTree cancer types.
  • CMA Lollipops: the same data, drawn as a lollipop plot. The height of a lollipop is the log10 of the number of carriers.

Data Access

The documentation pages of the individual tracks describe how to download the data and how to intersect it with other annotations.
