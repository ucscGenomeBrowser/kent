Description

This track is part of the Drug Targets collection. It shows 91 N-of-1 and N-of-few therapy projects from the N-of-1 Projects section of the N1C Gene Registry. Each project develops a genetic therapy, almost always an antisense oligonucleotide (ASO), for one disease-causing variant, or for a gene, in a single patient or a small group of patients. The projects are in 45 genes and are run by 23 institutions.

Display Conventions and Configuration

Each item is one project, labeled with the gene and the coding DNA change. Most projects are shown on the variant they target. Three projects that target a region, e.g. all variants in one exon, are shown on that region, and two gene knockdown projects without a variant (C9orf72 and GRIN1) are shown on the whole gene. Items are colored by the status of the project:

  Clinical Application: the therapy is given to a patient
  Developed
  Under Development
  Currently Not Pursued for Development, or Other

Hover over an item to see the variant, disease, status and institution. Click it for the approach, modality, the contact person of the project, whether cell lines or animal models are available, whether an Investigational New Drug (IND) application exists, publications, and a link to the entry in the N1C Gene Registry. The track can be filtered by status, approach, modality and target organ on the track configuration page.

Methods

The projects are submitted to the registry by N=1 Collaborative members, collaborators and other organizations, and are curated by the registry team. The registry lists the variant on GRCh38 as genomic HGVS and as RefSeq transcript HGVS, the disease with its MONDO identifier, the therapeutic approach (splice correction, exon skipping, exon inclusion, knockdown), the modality, the target organ and the contact information of the lab.

The data was downloaded from the N1C Gene Registry API at https://gene-registry.onrender.com/api/data?table=N1C_projects. All 91 projects are in the track. 86 were placed using their genomic HGVS. Their RefSeq transcript HGVS, mapped with our tool hgvsToVcf, agreed with the genomic HGVS for all 86, and the reference base of all 73 substitutions matched hg38. Three projects had a genomic range instead of a variant (ANKRD17, AP4M1, LNPK) and two had only a gene (C9orf72, GRIN1), which were placed on the gene's MANE Select transcript. The commands are documented in our makeDoc file and the scripts are in our source repository.

Data Access

The data can be explored interactively in table format with the Table Browser or the Data Integrator and exported from there to spreadsheet or tab-separated tables. From scripts, the data can be accessed through our API, track=n1cProjects.

For automated download and analysis, the annotation is stored in a bigBed file that can be downloaded from our download server. The file for this track is called n1cProjects.bb. Individual regions or the whole annotation can be obtained using our tool bigBedToBed, which can be compiled from the source code or downloaded as a precompiled binary for your system. Instructions for downloading source code and binaries can be found here. The tool can also be used to obtain features within a given range, e.g. bigBedToBed http://hgdownload.soe.ucsc.edu/gbdb/hg38/drugTargets/n1cProjects.bb -chrom=chr11 -start=0 -end=200000000 stdout

The original data can be downloaded from the N1C Gene Registry API. The registry data is free for nonprofit, academic and research use.
