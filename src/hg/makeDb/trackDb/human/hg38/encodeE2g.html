Description

This track shows predicted regulatory links between enhancers and the genes they control. The predictions were made by the ENCODE-rE2G model in 1,458 human biosamples: tissues, primary cells, cell lines, in vitro differentiated cells and organoids. ENCODE-rE2G was developed by the Engreitz lab as part of ENCODE4. It is a logistic regression model, trained on the results of CRISPR enhancer perturbation screens. The model scores every candidate element and gene pair within 5 Mb, using features computed from chromatin accessibility (DNase-seq), such as the activity-by-contact (ABC) score, the distance to the gene and the number of other elements and genes in between.

The track shows the thresholded predictions, the element-gene pairs that score above the cutoff the authors chose from the CRISPR benchmarks. It does not include the much larger set of all scored pairs.

Display Conventions

This is a faceted composite track. The table on the track settings page lists one row per biosample. It can be filtered by biosample classification, body system, treatment, donor sex and life stage, and searched by biosample, organ, treatment, donor and input experiment. Each biosample has two data types:

  • Element-gene links: one arc per predicted link, from the regulatory element to the transcription start site of the target gene. The label is the target gene. Clicking an arc shows the ENCODE-rE2G score of the link.
  • Elements: the regulatory elements themselves, one item per element and target gene, labeled with the target gene. An element that regulates several genes is shown once for each of them. The score can be filtered on the track settings page, and so can the element class (promoter, genic or intergenic). Hovering over an item in pack or full mode shows its target gene, score and distance to the TSS.

By default, the element-gene links of eight common ENCODE cell lines are shown: K562, GM12878, HepG2, H1, HCT116, A549, MCF-7 and IMR-90, all untreated. Items are colored by biosample classification: ■ tissue, ■ primary cell, ■ cell line, ■ in vitro differentiated cells and ■ organoid.

Methods

The thresholded predictions of all released ENCODE-rE2G annotations on GRCh38 were downloaded from the ENCODE portal through its API, in the bigInteract and bed formats. For each biosample, ENCODE-rE2G was run on one DNase-seq experiment, and a cell line with several DNase-seq experiments therefore has several annotations here, one per input experiment. The ENCODE accession of the input experiment is in the Input experiment column. Annotations of the "extended" ENCODE-rE2G model, available for K562 and GM12878, which also uses H3K27ac ChIP-seq and Hi-C, are not included.

The bigInteract files were converted to make the gene name the item label. Some element coordinates in the original files were written in scientific notation (e.g. chr15:7.8e+07-78000500); the element names were rebuilt from the coordinates. The bed files were converted to bigBed, with the ENCODE-rE2G score scaled to 0-1000 as the bed score. Biosample, treatment and donor information is from the ENCODE annotation, biosample and donor records.

Data Access

The data can be explored interactively with the Table Browser or the Data Integrator. From scripts, the data can be accessed through our API, one biosample and data type at a time, for example track=encodeE2g_ENCSR171UQE_links for the K562 links or encodeE2g_ENCSR171UQE_elements for the K562 elements. The track name encodeE2g refers to the whole set and holds no data of its own.

For automated download and analysis, the files can be downloaded from our download server, named by ENCODE annotation accession: <accession>.interact.bb and <accession>.elements.bb. The mapping from accession to biosample is in encodeE2g_metadata.tsv. The files can be converted to text with our tool bigBedToBed, which can be downloaded as a precompiled binary for your system from here, e.g. bigBedToBed http://hgdownload.soe.ucsc.edu/gbdb/hg38/encodeE2g/ENCSR171UQE.elements.bb -chrom=chr8 -start=127000000 -end=130000000 stdout.

The original files, including the full predictions without a threshold, are available from the ENCODE portal. The model code is at github.com/EngreitzLab/ENCODE_rE2G.
