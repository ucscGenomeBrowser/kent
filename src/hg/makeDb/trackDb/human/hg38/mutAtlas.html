Description

This track is part of the Cancer Mutations collection. It shows the somatic variants of the Cancer Mutation Atlas (CMA), made by the Karchin Lab at Johns Hopkins University. CMA combines somatic mutation calls from 12 tumor sequencing studies, including AACR Project GENIE, TCGA, Foundation Medicine and CPTAC, and counts for each variant how many patients carry it and how many patients were sequenced at this position, separately for more than 800 cancer types of the OncoTree classification. The atlas contains 3.9 million variants. 87% of them were found in only one patient, while about 20,000 were found in ten or more patients.

The same data is shown in two ways: the "Cancer Mutation Atlas" track draws every variant as a colored feature, and the "CMA Lollipops" track draws it as a lollipop whose height is the log10 of the number of carriers, so a variant with 10 carriers is drawn at height 1 and one with 1000 carriers at height 3.

Display Conventions and Configuration

Each item is one variant, which is one combination of position, reference allele and alternate allele. Several alternate alleles at the same position are separate items. The item label is the gene and protein change for variants in coding sequence, for example BRAF V600E, and the nucleotide change otherwise, e.g. C>T, delAG or ins26bp. Insertions are drawn as zero-length features at the insertion point, deletions cover the deleted bases.

Items are colored by the number of patients that carry the variant:

  100 or more carriers
  20 to 99 carriers
  5 to 19 carriers
  2 to 4 carriers
  1 carrier

Hovering over an item shows its effect, the number of carriers and tested patients over all studies, and the three cancer types with the most carriers. Clicking an item opens a page with a table of all cancer types and all studies with the variant.

The prevalence of a variant is the number of patients with the variant divided by the number of patients tested at its position. The number of tested patients changes from position to position, as most patients were sequenced with gene panels that cover only some genes. The field "Max. prevalence" is the highest prevalence in a single cancer type. To avoid values like 1 carrier out of 2 tested patients, only cancer types with at least 50 tested patients at the position are used for it, and it is empty if there is no such type.

The CMA counts are for patients and the cancer type that was assigned to them, without adding up related cancer types. For example, the counts for lung adenocarcinoma are not included in those for non-small cell lung cancer. The CMA website and its OpenCRAVAT annotator add up the counts along the OncoTree hierarchy.

Variants can be filtered by number of carriers, maximum prevalence, variant type, effect, OncoTree tissue and study. When zoomed out beyond 200 kbp, the "Cancer Mutation Atlas" track switches to a density graph. The lollipop track is only drawn for windows up to 2 Mbp.

Methods

CMA collects somatic variant calls from targeted panels, exomes and genomes of AACR Project GENIE release 18.0, the TCGA MC3 call set, Foundation Medicine, CPTAC, OrigiMed, the Chernobyl papillary thyroid cancer study (REBC), ALCHEMIST, Prostate 1000, METABRIC, IWG-MDS, Broad CLL and Duke DLBCL. Both tumor-only and matched tumor-normal studies are included. Variants are converted to GRCh38, checked against the reference genome and limited to the regions assayed by each sample's panel. Multiple samples of the same patient and cancer type are counted as one patient. Germline variants are removed if their allele frequency is above 0.04% in gnomAD v4, ALFA, Regeneron, All of Us, ESP6500 or 1000 Genomes, or if they are in the GATK panel of normals, unless they are a hotspot in Cancer Hotspots v2. See the CMA website and its list of studies for details.

We downloaded the file atlas.tsv of CMA version 2026.09.15 (beta1). The OncoTree names and tissues of the cancer types are from the OncoTree API, version oncotree_2025_10_03. We annotated the variants with bcftools csq using the Ensembl release 115 gene annotation. For each variant we show the most severe effect on an Ensembl canonical transcript, or, if no canonical transcript is affected, the most severe effect on any transcript. Variants outside all transcripts are labeled "intergenic". All 3,918,034 variants in the input file are in the track. The commands are in our makeDoc file and the scripts are in the cancerMutations scripts directory.

Data Access

The data can be explored interactively in table format with the Table Browser or the Data Integrator and exported from there to spreadsheet or tab-sep tables. From scripts, the data can be accessed through our API, track=mutAtlas.

For automated download and analysis, the annotation is stored in a bigBed file that can be downloaded from our download server. The file for this track is called mutAtlas.bb. Individual regions or the whole annotation can be obtained using our tool bigBedToBed, which can be compiled from the source code or downloaded as a precompiled binary for your system. Instructions for downloading source code and binaries can be found here. The tool can also be used to obtain features within a given range, e.g. bigBedToBed http://hgdownload.soe.ucsc.edu/gbdb/hg38/cancerMutations/mutAtlas.bb -chrom=chr21 -start=0 -end=100000000 stdout

The original data can be downloaded from the Cancer Mutation Atlas website.
