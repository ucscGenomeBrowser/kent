About Taxonium

Taxonium is a web application for exploring phylogenetic trees. Find out more at the Github repository (https://github.com/theosanderson/taxonium) or read the documentation (https://docs.taxonium.org).

About the tree

This tree was constructed by the Pathogen Genomics Group at the University of California Santa Cruz (UCSC) Genomics Institute. Our automated pipeline downloads Influenza A sequences from GenBank (i.e. the INSDC databases) and SRA assemblies from https://github.com/andersen-lab/avian-influenza/, aligns them to the RefSeq reference sequence for __STRAIN__ segment __SEGNUM__ (__SEGNAME__), __SEGREF__(https://www.ncbi.nlm.nih.gov/nuccore/__SEGREF__), using nextclade, and runs UShER to infer the tree structure and matOptimize to improve it under maximum parsimony.

About the metadata

In addition to metadata from GenBank and https://github.com/andersen-lab/avian-influenza (date, country, host, etc.), a "Differential selection in human vs. avian cells" phenotype score was calculated from Deep Mutational Scanning (DMS) experiments performed by the Bloom lab at the Fred Hutchinson Cancer Center (https://github.com/jbloomlab/PB2-DMS). The score displayed for each sequence was calculated by summing the per-mutation scores for all mutations found in that sequence, which are listed in the metadata as "Differential selection mutations".

Downloads

The tree and metadata files can be downloaded from https://hgdownload.gi.ucsc.edu/hubs/__ASMDIR__/UShER___SEGREF__ .
