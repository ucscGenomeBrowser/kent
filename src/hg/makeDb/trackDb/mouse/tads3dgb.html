Description

This track collection shows TAD domains from the 3D Genome Browser (3DGB) 2.0, across 30 mouse Hi-C and Micro-C datasets. Each subtrack is one 3DGB dataset. The displayed domain intervals are 3DGB's own, with no UCSC re-calling, merging, or recurrence scoring.

The calls are native to mm10. On mm39 they are shown lifted from mm10 (noted in each track's long label). By default a small set of reference datasets is shown (mESC, CH12-LX, and mESC WT MicroC). The others can be turned on from the track configuration page.

Display Conventions and Configuration

Each subtrack is colored by organ. These datasets are not a cross-comparable consensus. Each represents one dataset's own TAD calls. Because 3DGB calls TADs from Hi-C data analyzed in fixed-size 20 or 25 kb bins, domain edges are only accurate to roughly one bin. Domains do not cover the whole genome.

The facets are Organ, Cell type, Assay, Year, and Study. (The human 3DGB track additionally offers Condition, Treatment, and Provenance facets. Those were manually curated for the human datasets and are not provided here.)

Methods

TADs were called by the 3D Genome Browser from the cooltools insulation score, at 20 or 25 kb resolution. The 3DGB TAD file for each dataset was converted to a four-column bigBed (chromosome, start, end, dataset name). On mm10, domain coordinates were not changed. On mm39, domains were lifted from mm10 with the UCSC liftOver tool, and lifted domains that came out more than twice their mm10 size were removed. The dataset metadata used for the facets (organ, cell type, assay, year, study) was copied from the 3D Genome Browser.

Data Access

The raw data can be explored interactively with the Table Browser or the Data Integrator. For programmatic access, the track can be accessed using the Genome Browser's REST API. The underlying bigBed files can be downloaded from our download server. The complete original datasets are available from the 3D Genome Browser.
