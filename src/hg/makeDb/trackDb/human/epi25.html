Description

This track is part of the SNV Frequencies collection. It shows coding variants from the Epi25 browser of the Epi25 Collaborative, which presents the exome sequencing study of the Epi25 Collaborative (2024). The study compared the exomes of almost 21,000 individuals with epilepsy to 33,000 controls without known neurological or psychiatric conditions. The track contains 5.1 million variants, most of them rare.

For every variant, the track shows the allele counts and allele numbers in all epilepsy cases and in controls, so allele frequencies can be compared between the two. The cases are also split into the three main epilepsy types of the study: developmental and epileptic encephalopathy (DEE), genetic generalized epilepsy (GGE) and non-acquired focal epilepsy (NAFE).

Display Conventions

Each variant is drawn as a VCF item. Clicking a variant shows its details page with the consequence on the canonical transcript, the HGVS notation, the MPC and PolyPhen-2 scores, and the case and control counts. The consequence classes of the study are pLoF (predicted loss of function), damaging_missense (MPC ≥ 2), other_missense, synonymous and non_coding.

The original file lists the counts per analysis group: EPI, all epilepsy cases, and the subtypes DEE, GGE and NAFE. The field groups lists the groups in which a variant was seen, and the fields ac_case, an_case, ac_ctrl, an_ctrl, estimate, p_value and the others list one value per group, in the same order. To make this easier to read, we added these fields:

  • AC_CASE, AN_CASE, AF_CASE: allele count, allele number and frequency in all epilepsy cases (group EPI)
  • AC_CTRL, AN_CTRL, AF_CTRL: the same in controls
  • AC, AN, AF: cases and controls together
  • AC_DEE, AF_DEE, AC_GGE, AF_GGE, AC_NAFE, AF_NAFE (and the matching AN_ fields): counts and frequencies in the cases of each subtype, if the variant was counted in that group

The track can be filtered on all of these frequencies.

Methods

The Epi25 Collaborative collected samples from many cohorts of individuals with epilepsy. All samples were exome sequenced at the Broad Institute on Illumina HiSeq X or NovaSeq 6000, after capture with Illumina Nextera Rapid Capture, TruSeq Rapid Exome or a Twist custom kit. Reads were aligned to GRCh38 and variants called jointly with the GATK best-practice pipeline, then annotated with VEP, LOFTEE and MPC in Hail. Genotypes had to pass GQ ≥ 20, DP ≥ 20 and an allele balance between 0.2 and 0.8, and variants had to pass VQSR, lie in coding regions well covered by both capture kits, outside low-complexity regions, and pass call rate, case-control call rate difference and Hardy-Weinberg filters. After sample QC, ancestry matching of cases to controls and removal of related samples, 20,979 individuals with epilepsy (1,938 DEE, 5,499 GGE, 9,219 NAFE, 4,323 with other epilepsy syndromes) and 33,444 controls remained. The gene burden tests used ultra-rare variants, seen no more than five times in the dataset. See the reference below for details.

The variant results VCF file Epi25_variant_results.vcf.bgz (release of December 1, 2022) was downloaded from the Epi25 downloads page. It is already on GRCh38 and needed no liftover. A script added descriptions to the INFO fields, which were empty in the original file, changed the per-group fields to a variable number of values, as the number of groups differs between variants, and added the summary fields described above. The source file has 5,181,905 records. 49,504 of them have an annotation but no analysis group and no counts at all; these were removed, which leaves 5,132,401 variants. The steps are documented in our makeDoc file, and the script erbToVcf.py is in the scripts directory.

Data Access

Since the data can be downloaded from the Epi25 website, and does not seem to be under a license, we assume that we are allowed to redistribute it in VCF format. The data can be explored interactively with the Table Browser or the Data Integrator and exported from there to spreadsheet or tab-sep tables. From scripts, the data can be accessed through our API, track=epi25.

For automated download and analysis, the VCF file epi25.vcf.gz and its tabix index can be downloaded from our download server. The original data, together with gene-level results, can be downloaded from the Epi25 downloads page.
