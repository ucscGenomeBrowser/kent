Description

This collection shows two kinds of large-scale difference. One is the sequence that the new assembly resolves but the previous zebra finch reference did not contain, which is where most of the newly annotated genes are found. The other is structural variation between the two haplotypes of this individual, the inversions and translocations that separate the maternal and paternal copies of a chromosome.

This collection holds the Previously Unassembled and Large SVs tracks. Each has its own description page with the details of how it was made, reachable from the track name in the browser or from the list below the configuration controls on this page.

Data Access

The individual track description pages carry the download and intersection instructions for each annotation. The original files are on GenomeArk, in the bTaeGut7 annotations directory.
