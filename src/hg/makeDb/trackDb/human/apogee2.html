Description

This track is part of the Deleteriousness Predictions collection. It has data only on the mitochondrial genome (chrM). The mitochondrial genome encodes 13 proteins of the respiratory chain plus the 2 rRNAs and 22 tRNAs needed to translate them. The ACMG/AMP recommendations for mitochondrial variants name APOGEE 2 as the computational predictor for missense variants.

The track shows the APOGEE 2 score for missense variants and the nAPOGEE score for rRNA and tRNA variants, for all three possible substitutions at every position of chrM. The scores were computed by the APOGEE authors and are distributed through MitImpact.

Display Conventions and Configuration

There is one subtrack per substituted base (A, C, G, T). The height of a bar is the raw score, from 0 to 1. Zoom in until single bases are visible to see each bar. Hover over a bar to see its score. Positions without a bar are not scored by APOGEE 2 or nAPOGEE: synonymous, stop-gain, stop-loss and some start codon variants, the control region (D-loop), intergenic positions, and the base that is already in the reference sequence.

At the few positions where two genes overlap (MT-ATP8/MT-ATP6, MT-ND4L/MT-ND4 and some tRNA boundaries) a variant has one score per gene. Only the highest of the two is shown.

Bars are colored by the class of the variant. Both models use the same seven classes, which are defined by thresholds on the probability of pathogenicity.

  Likely pathogenic
  VUS+, variant of uncertain significance, closer to pathogenic
  VUS, variant of uncertain significance

Methods

APOGEE 2 (Bianco et al. 2023) is a bagging ensemble of k-nearest-neighbor classifiers with random undersampling and SMOTE oversampling, trained on 1,874 manually curated missense variants (140 pathogenic or likely pathogenic and 1,734 benign MITOMAP variants) with 17 mitochondrion-specific evolutionary, structural and positional features and the outputs of other predictors. Its score is converted to a Bayesian probability of pathogenicity, which defines the classes: Benign < 0.062, Likely benign 0.062-0.265, VUS- 0.265-0.396, VUS 0.396-0.544, VUS+ 0.544-0.716, Likely pathogenic 0.716-0.907, Pathogenic ≥ 0.907. nAPOGEE, introduced with MitImpact 4, applies the same seven classes to rRNA and tRNA variants, with separate thresholds for tRNAs and rRNAs. nAPOGEE has not been published yet.

The file MitImpact4_V059.zip (MitImpact 4, release V059) was downloaded from the MitImpact download page. It has 49,882 rows, one per variant. A Python script took only the columns APOGEE2_score, nAPOGEE_score and the two class columns. 13,627 rows have no score and are left out, which leaves 36,172 variants with a score. At 83 of them two genes overlap and the highest score is used. Bar height is the score, and the color comes from the class, stored in a second bigBed file per base. The commands are in the makeDoc file, the scripts in our source repository.

Data Access

The data can be explored interactively in table format with the Table Browser or the Data Integrator and exported from there to spreadsheet or tab-sep tables. From scripts, the data can be accessed through our API. Each substituted base is its own track, named apogee2_ followed by the base, for example track=apogee2_A.

For automated download and analysis, the scores are stored in bigWig files that can be downloaded from our download server. The files are called a.bw, c.bw, g.bw and t.bw. Individual regions can be obtained with our tool bigWigToBedGraph, which can be compiled from the source code or downloaded as a precompiled binary for your system. Instructions for downloading source code and binaries can be found here. The tool can also be used to obtain features within a given range, e.g. bigWigToBedGraph http://hgdownload.soe.ucsc.edu/gbdb/hg38/apogee2/a.bw -chrom=chrM -start=3200 -end=3300 stdout

The original data can be downloaded from the MitImpact download page. APOGEE 2 and nAPOGEE are licensed for non-commercial use only (CC BY-NC 4.0). Please cite the APOGEE 2 publication and MitImpact.
