Description

This track is part of the Drug Targets collection. It shows approved genetic therapies from the Marketed Genetic Therapies section of the N1C Gene Registry, placed on the gene that the registry lists for them: 38 drugs on 22 genes. This is usually the gene that causes the disease, which is not always the gene the drug acts on: nusinersen (Spinraza) changes the splicing of SMN2, but is shown on SMN1, the gene mutated in spinal muscular atrophy. Other examples are the exon-skipping ASOs for Duchenne muscular dystrophy and the siRNAs and ASOs against TTR.

Display Conventions and Configuration

Each item is one drug and gene, drawn over the MANE Select transcript of the gene. A drug with several target genes, e.g. Leqvio, which the registry lists for PCSK9, APOB and LDLR, is shown once on each gene. Items are colored by modality:

  RNA therapy (antisense oligonucleotides, siRNAs)
  Gene therapy
  Cell/gene therapy (cells modified with a gene therapy vector)

Hover over an item to see the drug, modality, target gene and condition. Click it for the company, the markets where it is approved, the mechanism and a link to DrugBank. The track can be filtered by modality on the track configuration page.

Methods

The registry team compiles the list of approved genetic therapies (RNA therapies, gene therapies and cell therapies) with their target gene, mechanism, company and the regions where they are approved.

The data was downloaded from the N1C Gene Registry API at https://gene-registry.onrender.com/api/data?table=marketed_drugs. The table has 110 rows. 67 have no target gene and are not in the track: 31 cell therapies such as cord blood products, 10 COVID-19 RNA vaccines, and 26 other RNA, gene or cell/gene therapies. The other 43 rows were placed on the MANE Select transcript of their gene, not on the coordinates in the registry, as these were wrong for two genes (ADA spans 1.4 Mbp, and the DDC gene therapy KEBILIDI had the position of DCC). The registry lists Upstaza, a gene therapy for aromatic L-amino acid decarboxylase (AADC) deficiency, under DCC; we show it on DDC. The commands are documented in our makeDoc file and the scripts are in our source repository.

Data Access

The data can be explored interactively in table format with the Table Browser or the Data Integrator and exported from there to spreadsheet or tab-separated tables. From scripts, the data can be accessed through our API, track=n1cMarketed.

For automated download and analysis, the annotation is stored in a bigBed file that can be downloaded from our download server. The file for this track is called n1cMarketed.bb. Individual regions or the whole annotation can be obtained using our tool bigBedToBed, which can be compiled from the source code or downloaded as a precompiled binary for your system. Instructions for downloading source code and binaries can be found here. The tool can also be used to obtain features within a given range, e.g. bigBedToBed http://hgdownload.soe.ucsc.edu/gbdb/hg38/drugTargets/n1cMarketed.bb -chrom=chrX -start=0 -end=156000000 stdout

The original data can be downloaded from the N1C Gene Registry API. The registry data is free for nonprofit, academic and research use.
