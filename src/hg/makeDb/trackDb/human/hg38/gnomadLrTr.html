Description

This track is part of the gnomAD collection. It shows tandem repeat (TR) loci genotyped in the first long-read release of gnomAD (version 0.1, October 2026), from PacBio HiFi genome sequencing of 1,027 All of Us participants and 292 HPRC/HGSVC samples. The cohorts are described on the gnomAD LR SVs page. Long reads span most tandem repeats completely, so the length of each repeat allele can be measured directly.

gnomAD shows the two cohorts separately. Here they are merged by TR locus, and every locus that is in the VCF of at least one cohort is shown once. The track contains 4.6 million loci. Every locus is a single item, even if it has many alleles: the allele sizes and their counts are shown on the details page and in the mouseover.

Display Conventions

Each item covers the reference repeat and is labeled with its motif. By default, all items are orange. On the track settings page, "Color by" can be switched to "Non-reference allele frequency": the items are then colored from light gray to red by the fraction of alleles that differ from the reference, over both cohorts. The scale is logarithmic:

  Default color, all loci
  Non-reference AF 0.0001 or lower
  Non-reference AF 0.001
  Non-reference AF 0.01
  Non-reference AF 0.1
  Non-reference AF 1

The allele sizes are given for each cohort as the length difference to the reference in bp, followed by the allele count, e.g. -3:2 +6:15 means that 2 alleles are 3 bp shorter and 15 alleles are 6 bp longer than the reference. An entry +0 is an allele with the same length as the reference but a different sequence. The details page links to the locus page in the gnomAD long-read browser, which shows the allele length distribution and repeat purity of all alleles.

The track can be filtered by TR catalog, reference length, non-reference allele frequency and count, cohort, VCF filter value and genomic context. No filter is active by default. When zoomed out to more than 200 kbp, the track is shown as a density graph.

Methods

Tandem repeats were genotyped with TRGT at the loci of two catalogs, TRExplorer v1.0.1 and Vamos v2.1. Each VCF record is one locus and lists all observed alleles of this locus as ALT alleles, with their allele counts. Details are in the gnomAD blog post and the pipeline on GitHub.

The per-chromosome VCF files of both cohorts were downloaded from the gnomAD Amazon S3 bucket, s3://gnomad-public-us-east-1/release/lr/0.1/vcf/, which is listed on the gnomAD long-read downloads page. All records with allele_type trv were kept and merged between the cohorts by their TR ID (TRID). For each cohort, the non-reference allele count is the sum of the counts of all ALT alleles, and alleles of the same length were summed for the allele size list. The non-reference allele frequency over both cohorts is the sum of the non-reference allele counts, divided by the sum of the allele numbers. The input had 4,599,174 All of Us and 2,447,044 HPRC/HGSVC loci, which gives 4,601,703 merged loci. 4,357 loci have an allele number of 0 (no sample was genotyped); their non-reference allele frequency is 0. The item starts after the VCF padding base, so it covers the repeat as given in the TR ID. The commands are in the makeDoc file and the scripts in the gnomadLr scripts directory.

Data Access

The data can be explored interactively in table format with the Table Browser or the Data Integrator and exported from there to spreadsheet or tab-separated tables. From scripts, the data can be accessed through our API, track=gnomadLrTr.

For automated download and analysis, the annotation is stored in a bigBed file that can be downloaded from our download server. The file for this track is called gnomadLrTr.bb. Individual regions or the whole annotation can be obtained using our tool bigBedToBed, which can be compiled from the source code or downloaded as a precompiled binary for your system. Instructions for downloading source code and binaries can be found here. The tool can also be used to obtain features within a given range, e.g. bigBedToBed http://hgdownload.soe.ucsc.edu/gbdb/hg38/gnomAD/lr/gnomadLrTr.bb -chrom=chr21 -start=0 -end=100000000 stdout

The original VCF files, which include per-allele motif counts and purity and, for HPRC/HGSVC, the sample genotypes, can be downloaded from the gnomAD long-read downloads page. gnomAD data is released without use restrictions.
