Description

This track shows TAD boundary stability (McArthur & Capra, 2021). For each 100 kb window of the genome, the track shows how many of 37 cell-type contact maps have a TAD boundary there. Boundaries shared by many cell types tend to have more CTCF binding and stronger evolutionary constraint, and are enriched for complex-trait heritability.

The 37 maps come from five sources: ENCODE cancer cell lines (12 maps), Schmitt 2016 (9), Rao 2014 (7), Dixon 2015 (5), and Leung 2015 (4). The TADs in all 37 maps were called by the original 3D Genome Browser with the directionality index method of Dixon et al., 2012. The Schmitt 2016 maps use the same Hi-C data as the Schmitt 2016 boundaries track.

McArthur & Capra divided boundaries into four groups (quartiles) by the number of maps sharing them:

  • 1 map (cell-type unique)
  • 2–4 maps
  • 5–13 maps
  • 14 or more maps

Display Conventions and Configuration

Each boundary is about 100 kb and is shaded from light (shared by 1 map) to dark (shared by all 37 maps). Use the filter to show only boundaries shared by at least a chosen number of maps. By default all boundaries are shown.

Methods

Each TAD's boundaries were represented as the 100 kb windows at both ends of the TAD. The genome was divided into 100 kb windows, and the number of maps with a boundary in each window was counted (McArthur & Capra, 2021). On hg19, the boundaries are shown at the positions listed in the authors' GitHub repository. The last boundary on chromosome 17 (chr17:81,100,001-81,200,000) runs 4,790 bp past the end of the chromosome. This boundary is shown ending at chr17:81,195,210, the last base of chromosome 17. On hg38, the boundaries were lifted with the UCSC liftOver tool, and a small fraction that could not be lifted were dropped. Lifted boundaries that came out more than twice their original size were also removed. Item names give the hg19 position, for example "hg19 chr1:600001-700000".

Data Access

The raw data can be explored interactively with the Table Browser or the Data Integrator. For programmatic access, the track can be accessed using the Genome Browser's REST API. The underlying bigBed files can be downloaded from our download server.
