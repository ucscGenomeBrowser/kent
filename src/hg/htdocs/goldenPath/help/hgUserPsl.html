Description

This track shows the BLAT alignments of your sequence(s) to the genome assembly. The data display can also be toggled to a density graph, or rearrangement display. In the Genome Browser, alignments of nucleotides use color to highlight differences as follows. Hold the mouse over a mark to see what it is, with its color in brackets, the bases or the number of bases.

  • red Mismatch: genome and query sequence have different bases at this position.
  • orange number: the query sequence has an insertion (or genome has a deletion / alignment gap) at this point. The number is the number of inserted bases.
  • purple Unaligned end: the query sequence extends beyond the end of the alignment.
  • green The query sequence appears to have a polyA tail that is not aligned to the genome.
  • double line: the alignment has gaps in both the genome and the query sequence.

Examples

Mismatch (red). One aligned base differs. The alignment continues on both sides.

genome  ACGTTGCAGTCAGGTCA
query   ACGTTGCAATCAGGTCA
                ^ red line here

Insertion in the query (orange). The query has three bases that the genome does not have. An orange "3" is drawn where they would go.

genome  ACGTTGCA---TCAGGTCA
query   ACGTTGCAGGGTCAGGTCA
                ^ orange "3" here

Gap in both sequences (double line). Between two aligned blocks, 5 genome bases and 4 query bases do not align to each other.

genome  ACGTTGCACTAGCTCAGGTCA
query   ACGTTGCAGATT-TCAGGTCA
                ^^^^^ double line here

Unaligned end (purple). The last two bases of the query differ from the genome. BLAT does not align them as mismatches, because an alignment that ends in mismatches scores lower than one that stops before them. So the alignment stops after the last matching base, and a purple line is drawn there.

genome  ACGTTGCAGTCAGGTCA
query   ACGTTGCAGTCAGGTTT
                       ^ purple line here, TT is not aligned

A short difference at the start or end of your sequence cannot be distinguished from a base difference. A mismatch in the first or last few bases is shown as a purple unaligned end, not as a red mismatch. The mouseover gives the number of unaligned bases: when it is only a few, they are most likely mismatches; when it is many, that part of the query may align elsewhere, or be missing from the assembly, or be vector or adapter sequence. To see the bases, click the alignment and open the alignment details: aligned bases are colored blue, unaligned ones are black.

When zoomed out, several mismatches can share one red line; the mouseover then lists their positions and bases. For more on these marks, see the alignment display help.
